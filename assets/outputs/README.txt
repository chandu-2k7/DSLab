Result images
=============
One image per sub-experiment: exp-1a.png ... exp-7c.png

For Experiment 5 these are the REAL matplotlib / seaborn charts produced by
those exact programs (line, bar, histogram + KDE, scatter and box plots).

For the other experiments they are clean console snapshots of the output that
was recorded during the lab.

They are generated by:

    python tools/generate-sample-media.py

and are shown by the code editor's "Result" panel so that the Run action
always produces a visible result - even for the parts that need network access
or an external service (see js/editor.js and js/config.js -> outputs).
